# 🧠 A* Algorithm Visualizer (AI Project)

🔗 **Live Demo:** https://a-star-algo-aii.netlify.app/

---

## 📌 Overview
This project is a web-based visualization of the **A* (A-Star) Search Algorithm**, one of the most efficient pathfinding algorithms used in Artificial Intelligence.

It demonstrates how the algorithm finds the shortest path between a start node and a goal node using heuristics in an interactive environment.

---

## 🚀 Features
- Interactive grid-based interface  
- Real-time pathfinding visualization  
- Step-by-step node exploration  
- Obstacle (wall) placement  
- Shortest path highlighting  
- Clean and user-friendly UI  

---

## 🧮 Algorithm Used

### A* Search Algorithm

A* combines:
- **g(n)** → Cost from start node  
- **h(n)** → Heuristic (estimated cost to goal)  

**Formula:**
f(n) = g(n) + h(n)

- Ensures optimal solution when heuristic is admissible  
- Faster than uninformed search algorithms
